Privacy Policy

Last updated: June 12, 2026

The short version: your API requests, collections, environments, tokens and response data never leave your machine. Tiger has no accounts and no cloud backend. The app sends anonymous usage statistics only, and you can turn them off with one switch.

What stays on your machine

Everything you work with: request definitions (.tiger files), environments and secrets, response bodies and headers, history, cookies, settings and certificates. Tiger stores them in folders you choose and in the app's local data directory. Requests are sent directly from your computer to the APIs you call; no proxy or relay operated by us is involved.

Anonymous usage analytics

To understand which features matter, Tiger records a small set of anonymous events through Google Analytics for Firebase:

  • app opened (version, platform)
  • request sent (HTTP method and status bucket such as 2xx or 4xx, never the URL)
  • collection imported (source format and request count)

These events never include URLs, hostnames, header values, request or response bodies, variable values, file paths or any personal information. The only identifier is a random, app-local ID that is not linked to you.

Opting out

Settings > Privacy > "Anonymous usage analytics" turns analytics off entirely. The switch takes effect immediately and persists.

Update checks

The app periodically checks for new versions by fetching a version file from this website and from GitHub Releases. These are ordinary HTTPS requests that carry no personal data.

The website

This website is a static site hosted on GitHub Pages. It sets no cookies and runs no analytics scripts. GitHub may log standard web server access data; see GitHub's privacy statement.
