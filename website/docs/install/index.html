Install Tiger

Tiger runs natively on macOS, Windows and Linux. All builds are published to GitHub Releases and the app checks for updates automatically in the background.

macOS
Signed and notarized DMG. Apple Silicon and Intel.
Windows
Microsoft Store, Setup installer or portable EXE.
Linux
AppImage (auto-updating) or Debian/Ubuntu .deb.

Download

All builds for the current release (v0.7.0) are on the GitHub Releases page. Pick the package for your platform below, or go straight to the releases page to see checksums and release notes.

macOS

Tiger is distributed as a signed and notarized .dmg for both Apple Silicon (arm64) and Intel (x64). Gatekeeper clears notarized apps on first launch, so you can open the DMG and drag Tiger to /Applications like any standard Mac application.

Install steps

  1. Go to github.com/jtaoufik/tiger/releases/latest and download the .dmg that matches your chip:
    • Tiger-mac-arm64.dmg - Apple Silicon (M1 and later)
    • Tiger-mac-x64.dmg - Intel
  2. Open the downloaded .dmg.
  3. Drag the Tiger icon to the Applications folder shortcut in the DMG window.
  4. Eject the DMG and open Tiger from Launchpad or /Applications.

Prefer no disk image? Each release also has a zip (Tiger-0.7.1-mac-arm64.zip / Tiger-0.7.1-mac-x64.zip): unzip it and move Tiger.app to /Applications. Both the DMG and the zip install update themselves in the app.

✓

Because Tiger is notarized by Apple, you do not need to right-click and choose Open to bypass Gatekeeper. It launches normally on first double-click.

System requirements

macOS 12 Monterey or later. Both Apple Silicon and Intel are natively supported.

Windows

Tiger is available for Windows x64 from the Microsoft Store (recommended), or as a Setup installer and a portable EXE for no-install / advanced use. A winget package (jtaoufik.Tiger) is pending review and will be added here once live.

Get it from Microsoft Store

Microsoft Store (recommended): signed by Microsoft, no warning, updates itself.

The options below are the no-install / advanced downloads from GitHub Releases.

i

Windows says "Windows protected your PC" / "unknown publisher"? That's Microsoft SmartScreen, which flags any exe from a publisher it hasn't seen enough downloads from yet - it doesn't mean the file is unsafe. Click More info, then Run anyway.

Option 1: Setup installer

  1. Download Tiger-Setup-windows-x64.exe from the releases page.
  2. Run the installer. If SmartScreen appears, click More info then Run anyway.
  3. Follow the setup wizard. You can choose a custom install directory. Tiger is added to your Start menu and a desktop shortcut is created.

Option 2: Portable EXE

Download Tiger-Portable-windows-x64.exe. This is a self-contained executable that you can run from any folder or USB drive without installing anything. Right-click the file and choose Run as administrator if you need to write to a restricted folder; otherwise run it directly. User data is stored in %APPDATA%\tiger-api-client regardless of where the EXE lives.

Option 4: Portable zip

Portable (zip): download Tiger-Portable-0.7.1-windows-x64.zip, unzip it anywhere and run Tiger.exe. Nothing is installed; delete the folder to remove it. Like the portable EXE, it does not update itself: Help > Check for Updates links you to the new zip.

System requirements

Windows 10 or later, x64 architecture.

Linux

Tiger ships three Linux downloads: an AppImage, a Debian/Ubuntu .deb and a plain tar.gz. Both are x64 only in this release.

Option 1: AppImage

The AppImage is a single portable file that runs on most x64 Linux distributions without installing anything. It also supports background auto-updates via electron-updater, so Tiger will notify you when a new version is available and offer to download and apply it.

  1. Download Tiger-linux-x64.AppImage from the releases page.
  2. Make it executable: 
    chmod +x Tiger-linux-x64.AppImage
  3. Run it: 
    ./Tiger-linux-x64.AppImage

To integrate it with your desktop environment, move the AppImage to ~/.local/bin/ or any directory on your $PATH and create a .desktop file pointing to it. Some distributions ship appimaged or similar tools that handle this automatically when you place an AppImage in ~/Applications.

Option 2: Debian / Ubuntu .deb

The .deb package installs Tiger system-wide and integrates with apt.

  1. Download Tiger-linux-amd64.deb from the releases page.
  2. Install it with apt (preferred over dpkg - it resolves dependencies automatically): 
    sudo apt install ./Tiger-linux-amd64.deb
  3. Launch Tiger from your application menu or run tiger-api-client in a terminal.

To uninstall: sudo apt remove tiger-api-client.

i

The .deb package does not auto-update. Check the releases page for new versions, download the updated .deb, and re-run sudo apt install ./<new-file>.deb to upgrade in place. The AppImage auto-updates and is recommended if you want hands-free upgrades.

Option 3: tar.gz

tar.gz: download Tiger-0.7.1-linux-x64.tar.gz, extract it and run ./tiger-api-client from the extracted folder: 

tar -xzf Tiger-0.7.1-linux-x64.tar.gz
cd Tiger-0.7.1-linux-x64
./tiger-api-client

The tar.gz does not update itself; download the new archive to upgrade.

System requirements

x64 architecture. The AppImage is distribution-agnostic (glibc 2.17+). The .deb targets Debian 11+ and Ubuntu 20.04+.

Background auto-updates

Tiger checks for new releases at startup and every six hours while running, downloads the update in the background (a small "Downloading update" indicator shows progress) and then shows Tiger X is ready. Restart to update. Choose Restart now, or Later to install it the next time you quit. Help > Check for Updates checks on demand. To be asked before anything is downloaded, turn off Install updates automatically in Settings > About.

In-app updates work for the Windows Setup install, the macOS .dmg and .zip, and the Linux AppImage. The Windows portable EXE and portable zip, the .deb and the tar.gz do not update themselves: Check for Updates links you to the new download instead. Microsoft Store installs are updated by the Store.

Auto-update downloads come from GitHub Releases. No third-party update server is involved. You can also update manually at any time by downloading the latest package from the releases page and replacing the existing install.

Build from source

Tiger is MIT-licensed and the full source is on GitHub. To build it yourself you need Node.js 20+ and npm. 

git clone https://github.com/jtaoufik/tiger.git
cd tiger
npm install
npm run dev          # launch in development mode (hot-reload)
npm run package      # build a distributable for your current platform

npm run package builds the Electron app and the MCP server binary, then produces platform-appropriate packages in the release/ folder. See CONTRIBUTING.md for the full development setup.
