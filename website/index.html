Free & open source · MIT

The free, open source API client that lives in Git

Tiger is a git-native API client for macOS, Windows and Linux, and a local-first alternative to Postman, Insomnia and Bruno. Your collections are plain-text .tiger files in your own Git repo, every request runs on your machine, and a built-in MCP server lets AI assistants such as Claude and Cursor run your saved requests. No account, no cloud, no lock-in.

Why Tiger

  • Git-native. Collections are human-readable text files. Diff them, branch them, review them in a pull request.
  • Local-first and offline. No backend and no sync service. Requests, tokens and responses stay on your machine.
  • No account. Download and go. Free for personal and commercial use under the MIT license.
  • Built for AI. The bundled MCP server exposes your saved requests as tools any MCP client can call.
  • Broad import support. Bring collections over from Postman, Insomnia, Bruno, OpenAPI, WSDL/SOAP or a curl command.
  • Cross-platform. Native desktop builds for macOS, Windows and Linux.

What is in Tiger 0.7.0

  • Save values to pass a response value into the next request, and Scripts & tests with pre-request and post-response JavaScript.
  • Collection runner and Load test for pass/fail runs and p50/p95 timings.
  • Team sync to share a collection through Git with one Sync with team button.
  • AI assistants (MCP) so Claude, Cursor and other MCP clients can list and run your requests.
  • Requests and auth including OAuth 2.0, GraphQL, multipart, proxies and client certificates (mTLS).
  • Environments and secrets with masked secret variables.

Download Tiger

Free, no sign-up. Every build is on GitHub Releases.

  • Windows: Setup installer or portable EXE. Microsoft Store and winget listings are coming soon.
  • macOS: Apple Silicon or Intel DMG, signed and notarized.
  • Linux: AppImage or .deb for Debian and Ubuntu.

Switching from Postman, Insomnia or Bruno

Export from your current tool and import the file into Tiger. Folders, requests, variables and auth carry over, and the result is a folder you can commit.
