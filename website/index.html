The git-native API client

Why Tiger

  • Git-native. Collections are human-readable text files. Diff them, branch them, review them in a PR.
  • Local-first & private. No backend and no telemetry of your traffic - requests, tokens and responses stay on your machine.
  • No account. Download and go. Free for personal and commercial use.
  • Broad import support. Bring collections over from Postman, Insomnia, Bruno, OpenAPI, WSDL/SOAP or a curl command.
  • Built for AI. The bundled MCP server exposes your saved requests as tools any MCP client can call.
  • Cross-platform. Native desktop builds for macOS, Windows and Linux.
