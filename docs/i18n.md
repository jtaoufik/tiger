# Translating Tiger

Tiger speaks English (source and fallback), Simplified Chinese (`zh-CN`), Hindi (`hi`),
Spanish (`es`), French (`fr`) and Arabic (`ar`, right to left). The app starts in the
system language when it is one of these, and Settings > General > Language switches live.

## Where text lives

```
src/core/i18n/
  locales.ts        supported locales, system-language matching, RTL
  translator.ts     t(key, vars), plurals (Intl.PluralRules), Intl number/date helpers
  messages/en/*.ts  English, one file per namespace (the source of truth for keys)
  messages/<loc>/   the same namespaces per locale, typed against English
  load.ts           lazy loading of non-English catalogs (renderer)
  all.ts            every catalog statically (main process, tests)
```

Every key starts with its namespace: `sidebar.newFolder` lives in `messages/en/sidebar.ts`.

## Using it

- React components: `const t = useT()` (from `src/renderer/src/i18n.ts`), then
  `t('sidebar.newFolder')`. The hook re-renders the component on a language switch.
- Outside render (toasts, `announce()`, event handlers): `import { t } from '../i18n'`.
- Main process: `mainT('menu.file')` from `src/main/i18n.ts`.
- Interpolation: `'Imported {name}'` with `t(key, { name })`.
- Plurals: `{ one: '{count} request', other: '{count} requests' }` with `t(key, { count })`.
  Arabic needs all six forms (`zero`, `one`, `two`, `few`, `many`, `other`); Hindi, Spanish
  and French need `one` and `other`; Chinese needs `other` only. `'=0'` overrides zero.
- Never build a sentence from fragments (`'Saved ' + name`): word order differs per
  language. Put the whole sentence in one message with placeholders.

`npm run i18n:check` (scripts/i18n-check.mjs) fails on hardcoded UI text and on catalog
gaps. Legit literals (product names, HTTP words, code) go in `scripts/i18n-allowlist.json`
or get an `// i18n-ignore` comment.

## What stays English

The `.tiger` file format keywords, HTTP methods, header names, code snippets, URLs, and
git terms shown in small print next to their plain-language translation
("Save a version (git commit)": the plain words are translated, `git commit` is not).

## Style per locale

| locale | buttons | sentences |
|---|---|---|
| fr | infinitive: Envoyer, Enregistrer | vous |
| es | infinitive: Enviar, Guardar | tú |
| zh-CN | verb: 发送, 保存 | neutral, no 您 overuse |
| hi | polite imperative: भेजें, सहेजें | आप |
| ar | verbal noun: إرسال, حفظ | Modern Standard Arabic, imperative for instructions |

No em dashes in English copy. Keep `{placeholders}` exactly as in English.
